How Bio Works Automation Pipeline

A private set of command-line tools that one creator uses to publish and manage original videos on the creator's own YouTube channels. There is no public sign-up and no third-party users.

What it does

  • Uploads finished videos (private by default) and sets thumbnails, the altered/synthetic-content disclosure and the default language.
  • Adds localized titles, descriptions and caption tracks in several languages.
  • Reads aggregate performance reports for the creator's own channels.
  • Lets the creator read the creator's own Gmail and Google Calendar from a personal assistant bot; mail is sent only when the creator explicitly confirms it.
