🔐 TikTok for Developers Integration & Scopes

      

        How BombZoo Studio integrates TikTok Login Kit and Content Posting API across our desktop/web publishing workflow.
      

      

        

          
1. Login Kit (user.info.basic)

          
Authenticates the studio's own TikTok channel accounts via OAuth 2.0 PKCE (`http://localhost:8722/`) and verifies the active account's `open_id` and `display_name` before any publishing action to prevent cross-channel posting errors.

        

        

          
2. Duplicate Prevention (video.list)

          
Queries `/v2/video/list/` on the authenticated account prior to publishing to verify that the episode's series label and caption have not already been posted, preventing accidental duplicate uploads.

        

        

          
3. Direct Post (video.publish)

          
Publishes completed 9:16 educational videos directly via `/v2/post/publish/video/init/` (`FILE_UPLOAD`) with `is_aigc: true` synthetic media disclosure automatically enabled on every post.

        

        

          
4. Inbox Draft Upload (video.upload)

          
Uploads video drafts to the creator's TikTok inbox via `/v2/post/publish/inbox/video/init/` when manual cover frame selection or final mobile review in the TikTok app is required.
