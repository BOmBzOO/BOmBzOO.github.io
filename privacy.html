Privacy Policy

How Bio Works Automation Pipeline · Last updated: October 9, 2026

1. Who uses this application

The application is a private tool operated by a single creator (contact below) for the creator's own Google account, the creator's own YouTube channels and the creator's own TikTok accounts. It has no public sign-up and no other users.

2. Google and YouTube API Services

The application uses YouTube API Services, the YouTube Analytics API, the Gmail API and the Google Calendar API. By using it, the operator agrees to the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy. The application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

3. TikTok API Services

The application uses TikTok Login Kit and the TikTok Content Posting API to publish the creator's own original videos to the creator's own TikTok accounts. Its use of TikTok data follows the TikTok Developer Terms of Service, and TikTok's handling of data is described in the TikTok Privacy Policy.

4. What data the application accesses and why

  • YouTube channel and video data of the creator's own channels: to upload videos, set thumbnails, the altered/synthetic-content disclosure, localized titles and descriptions, caption tracks and channel comments, and to check for duplicate uploads.
  • YouTube Analytics reports of the creator's own channels: aggregate figures such as views, watch time and subscriber counts, used for the creator's internal performance reports.
  • TikTok account data of the creator's own accounts: the basic profile (open ID and display name) to confirm which account is authorized, the list of the account's own public videos to check for duplicate posts before publishing, and permission to publish videos or send them to the TikTok inbox as drafts.
  • The creator's own Gmail: to read messages on the creator's request and to send a message only after the creator explicitly confirms it.
  • The creator's own Google Calendar: to read and add the creator's own events on request.

The application does not access data about other YouTube creators' channels, and it does not collect personal data of YouTube or TikTok viewers.

5. Storage and retention

  • OAuth tokens are stored only on the creator's own computers, in user-only configuration directories, and are used only to authorize the creator's own API requests.
  • Aggregate YouTube Analytics figures for the creator's own channels are stored in the creator's private database for internal reporting. They are deleted if the creator revokes the application's access or on request.
  • Gmail and Calendar content is processed on request and is not stored in any database.

6. Sharing

Data obtained through Google APIs or TikTok APIs is not sold, shared with, or transferred to any third party, and is not used for advertising or profiling.

7. Revoking access

Access can be revoked at any time from Google Account › Third-party connections, or for YouTube from the Google security settings page. TikTok access can be revoked in the TikTok app under Settings and privacy › Security › Apps and services permissions.
