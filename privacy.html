Privacy Policy

BombZoo Studio (How Bio Works Automation Pipeline) · Last updated: October 22, 2026

1. Who uses this application

BombZoo Studio is an educational media production and publishing platform operated by its creator team (contact below) for our official Google accounts, YouTube channels (How Bio Works KR/EN/JP, Market Autopsy, Farming.Insight, K-Drama Introduction), and TikTok accounts. Public visitors may browse our educational episode catalog and documentation without registering or providing personal data.

2. Google and YouTube API Services

The application uses YouTube API Services, the YouTube Analytics API, the Gmail API and the Google Calendar API. By using it, the operator agrees to the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy. The application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

3. TikTok API Services

BombZoo Studio uses TikTok Login Kit and the TikTok Content Posting API to publish our own original educational videos to our official TikTok accounts. Its use of TikTok data follows the TikTok Developer Terms of Service, and TikTok's handling of data is described in the TikTok Privacy Policy.

4. What data the application accesses and why

  • YouTube channel and video data of the studio's own channels: to upload videos, set thumbnails, the altered/synthetic-content disclosure, localized titles and descriptions, caption tracks and channel comments, and to check for duplicate uploads.
  • YouTube Analytics reports of the studio's own channels: aggregate figures such as views, watch time and subscriber counts, used for internal performance reports.
  • TikTok account data of the studio's own accounts: the basic profile (open ID and display name via user.info.basic) to confirm which account is authorized, the list of the account's own public videos (via video.list) to check for duplicate posts before publishing, and permission to publish videos (video.publish) or send them to the TikTok inbox as drafts (video.upload).
  • The creator's own Gmail: to read messages on the creator's request and to send a message only after explicit confirmation.
  • The creator's own Google Calendar: to read and add events on request.

The application does not access data about third-party YouTube or TikTok users, and it does not collect personal data from website visitors or viewers.

5. Storage and retention

  • OAuth tokens are stored only on the studio's secured workstations in user-only configuration directories and are used exclusively to authorize the studio's own API requests.
  • Aggregate analytics figures for the studio's own channels are stored in a private database for internal reporting and are deleted upon token revocation or request.

6. Sharing

Data obtained through Google APIs or TikTok APIs is never sold, shared with, or transferred to any third party, and is never used for advertising or user profiling.

7. Revoking access

Access can be revoked at any time from Google Account › Third-party connections, or for YouTube from the Google security settings page. TikTok access can be revoked in the TikTok app under Settings and privacy › Security › Apps and services permissions.
