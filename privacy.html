Privacy Policy

BombZoo Studio — Open Creator Publishing Platform · Last updated: October 30, 2026

1. Overview & Who Uses This Platform

BombZoo Studio (https://bombzoo.github.io/) is an open web-based publishing studio built for independent science communicators, educators, and financial literacy creators worldwide. Public visitors may browse the platform without registering, and any TikTok creator may voluntarily connect their TikTok account via TikTok Login Kit (OAuth 2.0) to preview, caption, and publish short-form educational videos to their own TikTok profile.

2. Data We Access via TikTok API Services

When a creator chooses to sign in with TikTok and grant permissions, BombZoo Studio accesses only the minimum scopes authorized by the user:

  • Basic Profile Information (user.info.basic): Retrieves the authenticated creator's open_id, display_name, and avatar URL via TikTok Login Kit to identify the connected session in the web studio header.
  • Creator Publishing Rules & Direct Post (video.publish): Calls /v2/post/publish/creator_info/query/ to display the creator's TikTok nickname, allowed privacy options (privacy_level_options), interaction permissions (Comment, Duet, Stitch), and maximum allowed video duration (max_video_post_duration_sec). When the creator explicitly clicks "Publish to TikTok", transmits the selected video file and creator-configured metadata via /v2/post/publish/video/init/ and checks processing status via /v2/post/publish/status/fetch/.
  • Inbox Draft Upload (video.upload): When the creator clicks "Send Draft to TikTok Inbox", uploads the video file via /v2/post/publish/inbox/video/init/ so the creator can finalize cover selection or audio in the TikTok mobile app.
  • Recent Published Videos (video.list): Queries /v2/video/list/ to display the authenticated creator's own recently published public TikTok videos inside the studio's "My Recent TikTok Videos" dashboard.

3. How We Use & Protect Your Information

  • We use TikTok API data solely to provide the interactive publishing studio features requested by the logged-in creator.
  • OAuth access tokens are used strictly for user-initiated requests during an active session and are immediately invalidated when the user clicks "Disconnect" or revokes access.
  • Video files selected by the creator in the browser are transmitted directly to TikTok's upload endpoints and are not permanently archived or redistributed by BombZoo Studio.

4. Data Sharing & Third Parties

BombZoo Studio never sells, rents, shares, or transfers any user data obtained through TikTok APIs to third parties, data brokers, or advertising networks. Our integration complies strictly with the TikTok Developer Terms of Service and the TikTok Privacy Policy.

5. Revoking Access & Data Deletion

Creators can disconnect their TikTok account at any time using the "Disconnect" button in the BombZoo Studio header, or revoke permissions directly in the TikTok mobile app under Settings and privacy › Security and permissions › Apps and services permissions. For data deletion inquiries, contact bombzoo78@gmail.com.
